# Post-Launch Roadmap

Skep's first launch is an open-source credibility play, not a rent-paying
business by itself. Keep the launch focused on the local tool, then use traction
to decide which opportunity path is worth pursuing.

## Opportunity Paths

### Consulting

The most realistic near-term path is helping teams adopt governed coding agents:

- integrate Skep with their existing agents, repos, and CI;
- write project policies for their workflows;
- train developers on sandbox, verify, approve, and audit habits;
- provide short-term support while the team rolls it out.

Keep the consulting CTA simple: the landing page already exposes a direct email
address. Treat serious issue threads or company questions as possible consulting
leads, but do not turn the core project into sales material.

### Hosted Skep

A hosted service is a later product, not part of the first public release. It
would need cloud sandboxes, GitHub App integration, tenant-aware auth, billing,
and scheduled runs. Build this only if launch users repeatedly ask for managed
runs instead of local installation.

### Funding

Funding becomes credible after traction, not before it. Useful signals are GitHub
stars, PyPI downloads, production users, and a clear hosted-product thesis. Until
those exist, keep fundraising as an option rather than the default path.

### Career Impact

The most dependable return is career impact. A working governance layer for AI
coding agents demonstrates sandboxing, worker contracts, re-verification,
approval UX, release engineering, and product taste in a timely problem space.

## First 6 Months

1. Month 1: stabilize launch feedback, fix reproducible bugs, and improve docs
   where users got stuck.
2. Month 2: finish the broader approval-to-template pipeline, including template
   narrowing.
3. Month 3: polish scheduled tasks around practical recurring workflows.
4. Month 4: harden Linux sandbox portability across more distributions.
5. Month 5: explore a hosted beta only if demand is concrete.
6. Month 6: tag v1.0 when the API, docs, and major workflows are stable.

Success after six months means active users, visible project traction, at least a
few contributors or serious evaluators, and a clear decision about whether Skep
is primarily consulting leverage, a hosted company, a funding story, or a career
signal.

## Six-Month Targets

Use these as planning targets, not vanity goals:

| Metric | Target | Stretch |
| --- | ---: | ---: |
| GitHub stars | 500 | 2,000 |
| PyPI downloads/month | 2,000 | 10,000 |
| Companies using Skep | 3-5 | 15-20 |
| Consulting revenue | $2K/mo | $8K/mo |
| Blog posts published | 8-12 | 20+ |
| HN front pages | 1-2 | 3-5 |
| Contributors | 3-5 | 10+ |
