Code of Conduct

Be excellent to each other.

This applies to all of skep's spaces: issues, discussions, pull requests, and any other channel the project runs.

The standard

  • Be respectful and constructive. Critique code and ideas, not people.
  • Assume good faith, especially with newcomers and non-native English speakers.
  • No harassment, discrimination, personal attacks, or sustained disruption — publicly or privately.
  • Keep discussions on topic and honest: if something is broken, say so plainly; if a claim is unverified, label it.
  • Respect maintainer decisions. Disagreement is welcome; relitigating settled decisions in every thread is not.

Reporting

If someone's behavior in a project space concerns you, email anmolnoor59@gmail.com with [skep conduct] in the subject. Reports are read by the maintainer, kept confidential, and acknowledged within a week.

Enforcement

Violations get a warning; repeated or severe violations get removed from project spaces. The maintainer's decision is final. This document is adapted in spirit from the Contributor Covenant.
