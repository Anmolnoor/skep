2026-07-30 Launch

skep v1.0.1 — govern your AI coding agent

The public launch. Skep is a local-first supervisor for coding agents: sandboxed execution in a disposable worktree, independent re-verification of whatever the agent claims, and a patch that reaches your repository only when you approve it. Daily-driven in the field since mid-July, roughly a hundred internal versions deep, and now one pipx install skep away.
